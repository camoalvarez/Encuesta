# Estímulos de encuesta para Qualtrics

Este repositorio aloja imágenes de elección de encuesta y otros archivos estáticos relacionados utilizados por un experimento de elección sobre rotaciones agrícolas implementado en Qualtrics.

## Estado

**Repositorio operativo de soporte de encuesta.** El repositorio permanece activo porque Qualtrics referencia archivos alojados aquí. No es el repositorio canónico de investigación, análisis ni replicación del proyecto.

## Propósito

Los archivos de este repositorio se utilizan como estímulos de encuesta y recursos de apoyo para el flujo de trabajo activo o mantenido en Qualtrics. Los nombres de archivo codifican atributos de las alternativas correspondientes y se preservan para evitar romper referencias existentes de la encuesta.

## Qué no está incluido

Este repositorio no contiene:

- datos de investigación a nivel de participante;
- el pipeline canónico de procesamiento de datos;
- el código actual de diseño experimental;
- el flujo de análisis empírico;
- un paquete de replicación listo para publicación.

## Flujo de investigación

El diseño experimental canónico, el análisis, la trazabilidad y los materiales de reproducibilidad se mantienen en el repositorio de investigación separado correspondiente al experimento de elección de rotaciones agrícolas.

## Política de mantenimiento

Como Qualtrics puede depender de las rutas exactas de los archivos alojados, los estímulos existentes no deben renombrarse, moverse ni eliminarse salvo que las referencias correspondientes en Qualtrics se actualicen y se prueben previamente.

Consultá [`QUALTRICS_MAINTENANCE.md`](QUALTRICS_MAINTENANCE.md) para ver el procedimiento seguro de actualización y la política de archivo al finalizar la encuesta.

Cuando la encuesta se retire de forma permanente y ya no requiera mantenimiento, este repositorio puede archivarse preservando los estímulos históricos y las URL utilizadas para mantener la trazabilidad.
